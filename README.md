# Conquer-the-Three-Kingdoms

TCG 尺寸标准的卡牌游戏前端框架（Vite + TypeScript）。

## 卡牌规格

- 标准尺寸：**宽 63 × 高 88**（TCG 比例，逻辑单位）
- 内框边距：左右 **3%**，上下 **4%**
- 电子设备上按视口**等比例缩放**，保持 63:88 比例

## 区域布局

| 区域 | 说明 |
|------|------|
| 场上 · 上半 | 战斗阶段为**敌方战场**；准备阶段清空敌方战场后转为**商店区** |
| 场上 · 下半 | **我方战场** |
| 手牌 | 我方手牌区 |

## 当前能力

- 标签为 **角色** 的卡牌可从手牌打出到**我方战场**（点击或拖拽）
- 预留 **动作**、**物品** 标签（手牌中动作卡会提示暂不可打出）
- **准备 / 战斗** 阶段切换（按钮）

## 开发

```bash
npm install
npm run dev
```

```bash
npm run build
```

## 目录结构

```
src/
  tcg/dimensions.ts   # TCG 尺寸与缩放
  game/
    types.ts          # 卡牌标签、区域、阶段
    state.ts          # 状态与阶段切换
    actions.ts        # 打出角色等操作
  ui/
    cardElement.ts    # 卡牌 DOM（含内框）
    gameBoard.ts      # 场上 + 手牌 UI
```
